Job radar

Private dashboard. Job data stays in your private GitHub repo; this page has none of it.

How to create the token (2 minutes)
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → your job-radar repo.
  3. Permissions → Repository → Contents: Read and write. Nothing else.
  4. Pick an expiration (for example 1 year), generate, and paste it here.

The token only ever goes to api.github.com. Use “Lock” on shared computers.
